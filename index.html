01 What is LiSA

不只是存储管理
而是数据的智能代理

面向本地、混合云与公有云的智能数据管理平台。独立于存储集群本身，以标准协议对接任意存储，把分散、异构、沉默的海量数据，统一纳入一个可检索、可流转、可治理的智能平面。

LiSA（Lenovo Intelligent Storage Agent）—— 面向企业级本地、混合云与公有云的智能数据管理平台，无缝集成 ONTAP、DXN 及第三方非结构化数据存储。

它不介入客户对存储访问的 IO 路径，而是以独立的元数据索引引擎为中枢，将 集中式、分布式、混合多云 之上的文件与对象数据，统一纳管、统一检索、统一流转。

微服务 / 模块化架构，按需叠加数据服务：异构存储统一纳管（类 FSx 多厂商 GUI 控制台）、文件/对象统一检索、拷贝/备份/归档/分层/复制 一站式工具箱、事件/策略驱动的工作流引擎 自动化数据治理，以及元数据搜索、自动打标、图像压缩等能力。

兼容 NetApp AIDE，支持本地 CPU/GPU 平台与定制化专业服务，让数据 AI-Ready，无缝对接 nVidia AIDP / Matrix ONE 等AI引擎。

架构说明 · Architecture

LiSA 数据分析模块基于 ClickHouse 列式引擎与元数据采集 Agent，对文件/对象做多维度洞察：

资产分析（类别分布 · 大小分布 · Top10 大文件）
时间分析（新增大小 · 累计大小趋势）
热度分析（热·温·冷·沉四等级 · 目录热度分布）

核心优势 · Advantages
  • ClickHouse 引擎：列式存储，千亿条目检索
  • 全协议采集 Agent：CIFS/NFS/S3/Lustre/GPFS 异构存储统一扫描
  • 三维度洞察：资产概览 · 时间分析 · 热度分析
  • API / SDK 开放：对接企业内部平台

架构说明 · Architecture

LiSA 数据归档基于元数据引擎筛选归档范围，通过策略驱动的工作流引擎自动执行归档任务。支持对象归档（DXN Object/S3）、云端归档（电信云/AWS/阿里云）、带库归档（v2.0 规划中）。低成本长期留存，同时保持可检索。

核心优势 · Advantages
  • 多目标归档：对象存储归档、云端归档、带库归档（v2.0）全覆盖
  • 可检索归档：归档数据仍纳入元数据检索范围，"死数据"可查
  • 策略驱动：基于生命周期的自动归档策略
  • 低成本留存：冷数据流转至低成本存储，降低总体成本
  • 混合多云：On-Premise + On-Cloud 统一归档管理

四大核心优势 让数据重新流动

独立引擎

Heterogeneous
集中式、分布式、混合多云统一纳管。标准协议（CIFS/NFS/S3/Lustre/GPFS）对接任意存储，跨品牌跨集群无差别管理。

智能流转

工业质检数据全生命周期治理

客户痛点

多存储集群并存数据查找困难；产线多变数据规范差；需按生命周期流转降本。

LiSA 方案

On-Prem + Cloud 统一纳管，文件/对象统一检索，智能 Agent 监控数据规范，按生命周期自动分层流转。

方案架构

多机台统一管理千亿秒级检索

客户痛点

历史数据杂乱查找困难；多机台数据无法统一管理；部分文件需留存 15 年。

LiSA 方案

智能标签解析规范元数据，汇总所有机台统一检索；提供 API 与企业内部平台对接，定时增量迁移与监控。

方案架构

异构对象存储迁移私有格式数据解析

客户痛点

日立 HCP 存储停产过保，需尽快迁移至新存储；迁移中要同步迁移合同对象的多个版本；日立 HCP 私有格式不支持标准 S3 读取。

LiSA 方案

支持对象多版本的 S3 数据迁移；定制开发日立 HCP 私有格式数据解析功能；支持任意数量的元数据标签，灵活增加；优化标签检索性能。
