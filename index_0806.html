01 What is LiSA

不只是存储管理
而是数据的智能代理

面向本地、混合云与公有云的智能数据管理平台。独立于存储集群本身，以标准协议对接任意存储，把分散、异构、沉默的海量数据，统一纳入一个可检索、可流转、可治理的智能平面。

LiSA（Lenovo Intelligent Storage Agent）—— 面向企业级本地、混合云与公有云的智能数据管理平台，无缝集成 ONTAP、DXN 及第三方非结构化数据存储。

它不介入客户对存储访问的 IO 路径，而是以独立的元数据索引引擎为中枢，将 集中式、分布式、混合多云 之上的文件与对象数据，统一纳管、统一检索、统一流转。

微服务 / 模块化架构，按需叠加数据服务：异构存储统一纳管（类 FSx 多厂商 GUI 控制台）、文件/对象统一检索、拷贝/备份/归档/分层/复制 一站式工具箱、事件/策略驱动的工作流引擎 自动化数据治理，以及元数据搜索、自动打标、图像压缩等能力。

兼容 NetApp AIDE，支持本地 CPU/GPU 平台与定制化专业服务，让数据 AI-Ready，无缝对接 nVidia AIDP / Matrix ONE 等AI引擎。

① 资产概览（类别分布 · 大小分布 · Top10 大文件）

  • ClickHouse 引擎：列式存储，千亿条目检索

  • API / SDK 开放：对接企业内部平台

LiSA 数据归档基于元数据引擎筛选归档范围，通过策略驱动的工作流引擎自动执行归档任务。支持对象归档（DXN Object/S3）、云端归档（电信云/AWS/阿里云）、带库归档（v2.0 规划中）。低成本长期留存，同时保持可检索。

  • 策略驱动：基于生命周期的自动归档策略
  • 低成本留存：冷数据流转至低成本存储，降低总体成本
  • 混合多云：On-Premise + On-Cloud 统一归档管理
